#Revela Analyzer

Revela Analyzer is a software tool for analyzing and visualizing electric power system reliability simulation data.

It reads and organizes data generated by simulation software such as Revela and PS-MORA.

Revela Analyzer does not perform simulations.

The software provides tools for importing, organizing, analyzing, comparing, and visualizing simulation cases.

Imported cases are stored as copies for use within the software.

The database is used for data organization and analysis and must not be considered a backup of the original files.

Version V0 is an initial and experimental version and may contain errors or limitations.

Results should always be verified against the original simulation files before being used for important decisions.

The software is provided free of charge.

Purpose: Reliability data analysis and visualization
Version: V0
